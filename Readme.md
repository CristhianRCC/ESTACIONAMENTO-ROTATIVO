# Estacionamento Rotativo

Projeto em C para gerenciamento de estacionamento.Este projeto foi desenvolvido com o objetivo de gerenciar o funcionamento de um estacionamento rotativo.

O usuário informa a placa do veículo , o tipo do veículo e o tempo de permanência. Após isso, o sistema calcula o valor base do preço, verifica se há descontos ou multas e exibe o valor final a pagar.
