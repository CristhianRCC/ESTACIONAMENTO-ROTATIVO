# Estacionamento Rotativo

Projeto em C para gerenciamento de estacionamento.Este projeto foi desenvolvido com o objetivo de gerenciar o funcionamento de um estacionamento rotativo. O usuário informa a placa do veículo , o tipo do veículo e o tempo de permanência. Após isso, o sistema calcula o valor base do preço, verifica se há descontos ou multas e exibe o valor final a pagar.

# Entradas do Usuário

- Placa do veículo
- Tipo de veículo
- Tempo de permanência (horas)

# Processamento 

1. Identificação dos dados informados pelo usuário
2. Cálculo do valor base de acordo com o tempo
3. Verificação de descontos ou multa
4. Exibição do resultado final

# Saída

- Placa
- Tipo de veículo
- Valor base
- Descontos ou multas
- Valor final a pagar
